# 모래 한 스쿱 — 시간 (Sand of Time)

관람객이 모래를 흘려보내면, 흘려보낸 양에 따라 크기가 다른 모래 피규어가 생겨 빛을 향해 걸어가는 미디어 아트입니다.

## 파일 구성
- `index.html` : 전시 화면 (브라우저에서 바로 열림)
- `README.md` : 이 문서

## 실행 방법
1. `index.html`을 더블클릭하거나 브라우저로 끌어다 놓습니다.
2. 주소 뒤에 `#show`를 붙이면 바로 전시 화면으로 열립니다. 예: `index.html#show`
3. 전시 화면 우측 상단 `데모` 버튼을 누르면 임의의 피규어가 생성됩니다.

## 조작
- 드래그: 둘러보기
- 휠 / 두 손가락: 확대·축소
- `자동회전 끄기`: 자동 회전 on/off

## 이벤트 규약 (센서 연동 예정)
무게센서, 적외선 센서, 터치디자이너에서 웹 페이지로 보낼 메시지 형식입니다.

- 무게 저장: `{"type":"weight","g":12.3}`
- 흐름 시작: `{"type":"flow","state":"start"}`
- 흐름 종료: `{"type":"flow","state":"end"}`

## 작업 메모
- 현재 입력은 데모 버튼으로만 동작합니다. 센서 연동 시 같은 함수(`addFigure`)로 신호를 넘기면 됩니다.
- 외부 서버나 데이터베이스를 쓰지 않으므로 GitHub Pages에서도 그대로 동작합니다.
