# 모래 한 스쿱 — 시간 (Sand of Time)

관람객이 모래를 흘려보내면, 흘려보낸 양에 따라 크기가 다른 모래 피규어가 생겨 빛을 향해 걸어가는 미디어 아트입니다.

## 파일 구성
- `index.html` : 전시 화면 (브라우저에서 바로 열림)
- `README.md` : 이 문서

## 실행 방법
1. `index.html`을 더블클릭하거나 브라우저로 끌어다 놓습니다.
2. 주소 뒤에 `#show`를 붙이면 바로 전시 화면으로 열립니다. 예: `index.html#show`
3. 전시 화면 우측 상단 `데모` 버튼을 누르면 임의의 피규어가 생성됩니다.

## 조작
- 드래그: 둘러보기
- 휠 / 두 손가락: 확대·축소
- `자동회전 끄기`: 자동 회전 on/off

## 이벤트 규약 (센서 연동 예정)
무게센서, 적외선 센서, 터치디자이너에서 웹 페이지로 보낼 메시지 형식입니다.

- 무게 저장: `{"type":"weight","g":12.3}`
- 흐름 시작: `{"type":"flow","state":"start"}`
- 흐름 종료: `{"type":"flow","state":"end"}`

## 작업 메모
- 현재 입력은 데모 버튼으로만 동작합니다. 센서 연동 시 같은 함수(`addFigure`)로 신호를 넘기면 됩니다.
- 외부 서버나 데이터베이스를 쓰지 않으므로 GitHub Pages에서도 그대로 동작합니다.

# 시간의 정원 (garden/)

오늘 살아낸 자아의 수만큼 모래를 부으면, 화면에도 모래가 내려 땅이 만들어지고 그 자리에서 꽃이 피어 정원에 쌓이는 웹 프로토타입입니다.

## 주소
- 정원(전시 화면): `https://arang2709.github.io/sand-of-time/garden/#show`
- 참여 화면(휴대폰): `https://arang2709.github.io/sand-of-time/garden/`
- 꽃이 미리 자란 상태로 시작(발표용): `https://arang2709.github.io/sand-of-time/garden/?seed=20#show`

- 다른 사람 입력 없이 이 화면에서만 시험(디자인 확인용): 주소에 `?local` 추가. 예: `.../garden/?local&show`

## 조작 (전시 화면)
- `데모` 버튼 또는 숫자 키 `1`~`9`, `0`(=10): 그 수만큼 모래를 부은 것처럼 모래가 내리고 꽃이 핍니다.
- `F` 키 또는 `전체 화면` 버튼: 전체 화면
- 4초 동안 조작이 없으면 버튼이 숨겨집니다. 마우스를 움직이면 다시 나타납니다.

## 규칙
- 꽃 송이 수 = 부은 스쿱 수
- 꽃 크기 = 무게 구간 (1~2 봉오리, 3~4 작은 꽃, 5~6 중간 꽃, 7 이상 시그니처 꽃)
- 꽃 색 = 관람객마다 다른 씨앗
- 꽃은 사라지지 않고 쌓이며, 자리가 차면 정원이 뒤로 깊어지고 화면이 천천히 물러납니다.

## 센서 연결용 함수
아두이노 신호를 받는 코드에서 아래를 호출하면 됩니다.
- `garden.flowStart()` : 모래가 흐르기 시작 (화면에 모래가 내리기 시작)
- `garden.flowEnd(스쿱수)` : 모래가 멈춤 (모래가 그치고 꽃이 핌)

## 3D 버전 (garden3d/)
같은 네온 선 꽃으로 만든 두 장면 구성입니다. 규칙과 센서 함수는 2D 버전과 같습니다.
1. **붓는 장면**: 모래가 내리는 동안 내 꽃의 모양과 크기가 드러납니다. 부은 양만큼 송이가 늘고, 구간을 넘으면 꽃이 커집니다.
2. **정원 장면**: 넓은 3D 모래밭에 모두의 꽃 무리가 서 있습니다. 방금 핀 꽃으로 카메라가 다가갔다가 정원 전체로 물러납니다.

- 정원(전시 화면): `https://arang2709.github.io/sand-of-time/garden3d/#show`
- 참여 화면(휴대폰): `https://arang2709.github.io/sand-of-time/garden3d/`
- 발표용: `https://arang2709.github.io/sand-of-time/garden3d/?seed=20#show`
- 드래그로 둘러보기, 휠·두 손가락으로 확대·축소. 6초 동안 조작이 없으면 다시 천천히 돕니다.
- 붓는 중 실시간 반영용 함수: `garden.flowProgress(지금까지 부은 g)`
